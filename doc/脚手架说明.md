# 前端项目脚手架说明

## 项目概述

这是一个基于 Turborepo 的前端项目脚手架，包含两个应用程序（admin 和 platform）以及共享包。该脚手架采用现代前端技术栈，提供可扩展、可维护的架构。

## 技术栈

- **Monorepo**: [Turborepo](https://turbo.build/)
- **框架**: [React](https://reactjs.org/) (v18+)
- **运行时**: [Vite](https://vitejs.dev/)
- **语言**: [TypeScript](https://www.typescriptlang.org/)
- **状态管理**: [Zustand](https://github.com/pmndrs/zustand)
- **样式**: [Tailwind CSS](https://tailwindcss.com/)

## 安装与启动

1. 安装依赖：
   ```bash
   pnpm install
   ```

2. 启动开发服务器：
   ```bash
   pnpm dev
   ```

   这将同时启动 admin (端口 3000) 和 platform (端口 3001) 应用。

3. 构建生产版本：
   ```bash
   pnpm build
   ```

## 脚本命令

- `pnpm dev` - 启动所有应用的开发服务器
- `pnpm build` - 构建所有包和应用
- `pnpm lint` - 检查所有包和应用的代码质量
- `pnpm format` - 格式化所有代码

## 应用程序

### 管理后台应用 (`apps/admin`)
- 端口：3000
- 用途：管理后台和管理工具
- 特性：示例组件用于管理用户、内容和设置

### 平台应用 (`apps/platform`)
- 端口：3001
- 用途：面向用户的平台应用
- 特性：示例组件用于用户交互和内容消费

## 共享包

### UI 包 (`packages/ui`)
可在多个应用间复用的UI组件。

### 工具包 (`packages/utils`)
共享的工具函数和使用 Zustand 的状态管理仓库。

## 开发规范

- `packages/*` 中的代码在应用间共享
- 对共享包的更改会自动触发依赖应用的重建
- 每个应用维护自己的依赖，同时共享公共组件
- 在所有包和应用中使用相同的编码标准

## Tailwind CSS 配置

项目中已集成 Tailwind CSS，每个应用都有独立的配置文件：

- `apps/admin/tailwind.config.js`
- `apps/platform/tailwind.config.js`
- `apps/admin/postcss.config.js`
- `apps/platform/postcss.config.js`

Tailwind 提供了实用优先的 CSS 类，加快开发速度并保持设计一致性。

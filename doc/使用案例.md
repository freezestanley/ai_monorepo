# 前端项目脚手架使用案例

## 案例一：快速搭建企业管理系统

### 场景描述
一家互联网公司需要快速搭建一套企业内部管理系统，包含用户管理、数据统计、系统设置等功能模块。

### 实现步骤

1. **初始化项目**
   ```bash
   # 使用已有的脚手架作为基础
   git clone <repository-url>
   cd refactor
   pnpm install
   ```

2. **修改 Admin 应用**
   - 修改 `apps/admin/src/App.tsx` 添加新的功能模块
   - 在 `apps/admin/src/components/` 下创建用户管理组件

   ```tsx
   // apps/admin/src/components/UserManagement.tsx
   import { useState } from 'react';

   interface User {
     id: string;
     name: string;
     email: string;
     role: string;
   }

   export const UserManagement = () => {
     const [users, setUsers] = useState<User[]>([
       { id: '1', name: '张三', email: 'zhang@example.com', role: 'admin' },
       { id: '2', name: '李四', email: 'li@example.com', role: 'user' },
     ]);

     return (
       <div className="bg-white rounded-lg shadow p-6">
         <h2 className="text-xl font-bold mb-4">用户管理</h2>
         <div className="overflow-x-auto">
           <table className="min-w-full divide-y divide-gray-200">
             <thead className="bg-gray-50">
               <tr>
                 <th className="px-6 py-3 text-left text-xs font-medium text-gray-500 uppercase tracking-wider">姓名</th>
                 <th className="px-6 py-3 text-left text-xs font-medium text-gray-500 uppercase tracking-wider">邮箱</th>
                 <th className="px-6 py-3 text-left text-xs font-medium text-gray-500 uppercase tracking-wider">角色</th>
               </tr>
             </thead>
             <tbody className="bg-white divide-y divide-gray-200">
               {users.map(user => (
                 <tr key={user.id}>
                   <td className="px-6 py-4 whitespace-nowrap">{user.name}</td>
                   <td className="px-6 py-4 whitespace-nowrap">{user.email}</td>
                   <td className="px-6 py-4 whitespace-nowrap">
                     <span className={`px-2 inline-flex text-xs leading-5 font-semibold rounded-full
                       ${user.role === 'admin' ? 'bg-red-100 text-red-800' : 'bg-green-100 text-green-800'}`}>
                       {user.role}
                     </span>
                   </td>
                 </tr>
               ))}
             </tbody>
           </table>
         </div>
       </div>
     );
   };
   ```

3. **集成到应用**
   - 在 Admin 应用中引入新组件
   - 更新路由或导航菜单

4. **使用共享组件和工具**
   - 复用 `packages/ui` 中的按钮组件
   - 使用 `packages/utils` 中的状态管理

### 优势体现
- 快速搭建界面：使用 Tailwind CSS 快速构建响应式 UI
- 代码复用：共享组件和工具函数减少重复开发
- 类型安全：TypeScript 确保类型安全
- 状态管理：Zustand 提供简洁的状态管理方案

## 案例二：构建 SaaS 平台

### 场景描述
开发一个多租户 SaaS 平台，需要提供用户友好的前台体验和功能丰富的后台管理。

### 实现步骤

1. **平台应用定制**
   - 扩展 `apps/platform` 创建用户订阅、产品展示页面
   - 利用 Tailwind CSS 创建现代化的用户界面

   ```tsx

     name: string;

     features: string[];

   ```

2. **后台管理功能**
   - 在 `apps/admin` 中添加数据监控、用户分析等功能
   - 使用 Zustand 管理全局状态

   ```tsx
   // 在 packages/utils/store.ts 中添加数据监控状态
   interface AnalyticsState {
     metrics: {
       dailyUsers: number;
       monthlyRevenue: number;
       conversionRate: number;
     };
     loading: boolean;
     fetchMetrics: () => Promise<void>;
   }

   export const useAnalyticsStore = create<AnalyticsState>((set) => ({
     metrics: {
       dailyUsers: 0,
       monthlyRevenue: 0,
       conversionRate: 0,
     },
     loading: false,
     fetchMetrics: async () => {
       set({ loading: true });
       // 模拟 API 调用
       await new Promise(resolve => setTimeout(resolve, 1000));
       set({
         metrics: {
           dailyUsers: 1242,
           monthlyRevenue: 24569,
           conversionRate: 3.24,
         },
         loading: false,
       });
     },
   }));
   ```

3. **样式统一**
   - 通过 Tailwind CSS 主题确保两套应用视觉一致性
   - 在根 CSS 文件中自定义主题

### 优势体现
- 架构分离：前后台应用职责分明
- 代码共享：共用 UI 组件和工具函数
- 开发效率：Vite 提供快速的开发体验
- 设计一致：Tailwind CSS 保证视觉统一

## 案例三：多品牌产品线开发

### 场景描述
大型集团企业需要为不同品牌开发多个独立的应用，但希望共用基础设施。

### 实现步骤

1. **扩展项目结构**
   - 基于现有脚手架创建更多应用
   - 在 `apps/` 目录下增加品牌应用

2. **品牌定制**
   - 为每个品牌创建特定的主题文件
   - 利用 Tailwind CSS 的主题功能实现差异化

   ```js
   // apps/brand-a/tailwind.config.js
   /** @type {import('tailwindcss').Config} */
   export default {
     content: [
       "./index.html",
       "./src/**/*.{js,ts,jsx,tsx}",
     ],
     theme: {
       extend: {
         colors: {
           primary: {
             50: '#eff6ff',
             500: '#3b82f6',
             900: '#1e3a8a',
           }
         }
       },
     },
     plugins: [],
   }
   ```

3. **共享业务逻辑**
   - 将通用业务逻辑放在 `packages/` 中
   - 不同品牌可复用相同的数据处理逻辑

### 优势体现
- 资源共享：共用构建工具和开发流程
- 品牌独立：各品牌可独立定制外观
- 团队协作：统一的开发规范和流程
- 成本控制：基础设施复用降低成本
